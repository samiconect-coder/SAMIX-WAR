# SAMIX WAR — DZ EDITION

نسخة أولية كاملة المصدر لتطبيق Android يعمل دون إنترنت.

## محتويات النسخة
- تطبيق Android WebView يفتح اللعبة محلياً دون صلاحية إنترنت.
- واجهة عربية بطابع جزائري وألوان أخضر/ذهبي/كحلي وزخارف هندسية.
- شاشة رئيسية، تجهيز المهمة، إعدادات، حول اللعبة.
- نموذج أركيدي تجريبي: لاعب + 19 حليفاً آلياً ضد 20 خصماً آلياً.
- عناصر تحكم باللمس، زر نبضة خيالي، وساحتان تجريبيتان.
- إعداد GitHub Actions لبناء APK تلقائياً.

## إضافة موسيقى البداية
ضع تسجيلاً تملك حق استخدامه باسم `intro.mp3` في:
`app/src/main/assets/audio/intro.mp3`

الملف الصوتي الذي أُرسل في المحادثة لم يكن متاحاً كملف محلي أثناء إنشاء ZIP، لذلك لم يُضمّن تلقائياً.

## بناء APK عبر GitHub
1. أنشئ مستودعاً جديداً باسم `SAMIX-WAR`.
2. ارفع جميع محتويات هذا المجلد إلى جذر المستودع.
3. افتح تبويب Actions.
4. شغّل `Build SAMIX WAR APK` أو انتظر انتهاء البناء بعد الرفع.
5. افتح نتيجة التشغيل الناجحة ثم نزّل Artifact باسم `SAMIX-WAR-debug-apk`.
6. فك ZIP الناتج لتحصل على `app-debug.apk`.

## ملاحظات
- هذه نسخة Prototype وليست لعبة 3D نهائية.
- المعارك رمزية أركيدية وليست محاكاة واقعية للأسلحة أو التدريب العسكري.
- لا توجد صلاحية إنترنت في التطبيق.
- البناء يتطلب Android SDK الذي يجهزه GitHub Actions.
